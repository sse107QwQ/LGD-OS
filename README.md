# ENGLISH 英文
# LGD-OS
This is a Linux-style DOS on Windows
# New Features
calc now supports -S to solve systems of linear equations with multiple variables (see help inside the shell for details)
The mahjong function is temporarily disabled and not in use.
# Bug Fixes
Fixed the bug where touch created files in UTF-8 that previously caused garbled text.
Fixed the bug where edit only supported .txt and .log filenames, deleted the create file without file function, **please use touch to add files first!!**
